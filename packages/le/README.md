# TMO-LE Profile

A complete, versioned TypeScript implementation of the TMO law-enforcement application profile.

## Contents
- canonical resource model
- LE-101 through LE-107 invariant validator
- ternary evaluation result
- provenance-aware proposition evidence scoring
- deterministic and property-based tests
- normative profile specification

## Commands
```sh
npm install
npm run build
npm test
npm run test:ci
```
